# Замена автоэнкодера на свой алгоритм
Тестовый стенд представляет собой кластер TarantoolDB из двух шардов и двух роутеров.
Пример приложения производит запись строк пачками через выбранный роутер.
После записи производится чтение записанных строк.

В данном примере повышена на 20% производительность записи за счёт замены
автоэнкодера в MsgPack своим алгоритмом. См. метод `EncodeMsgpack`.

В качестве примера производится также чтение записанных значений и их декодирование
собственным алгоритмом. См. метод `DecodeMsgpack`.

Формат спейса в приложении и в кластере отличаются. В приложении только пользовательские
столбцы:
```go
type TestRecord struct {
    Id  uint64 `json:"id"`
    Too uint64 `json:"too"`
    Foo string `json:"foo"`
}
```

В базе данных в данном спейсе есть дополнительный столбец для шардинга - `bucket_id`:
```lua
box.space.test:format({
    { name = 'id', type = 'number' },
    { name = 'bucket_id', type = 'unsigned' }, -- << --
    { name = 'too', type = 'number' },
    { name = 'foo', type = 'string' },
})
```

Поэтому при кодировании данных мы вторым полем пишем `nil`, а при декодировании
мы его пропускаем.

## Запуск примера
Для успешного запуска должны быть свободны порты:
* 3301 .. 3306
* 8081 .. 8086

Запуск стенда производится командой:
```shell
cd ./doc/examples/go_custom_encoder/tt
docker compose up -d
```

После запуска должны работать все контейнеры, кроме `tarantool-db-init`. Также
после запуска доступна админка кластера TarantoolDB по адресу: http://localhost:8081

Откройте админку кластера и визуально убедитесь, что нет каких либо предупреждений,
или ошибок. Сразу после старта в течении нескольких секунд могут быть предупреждения,
так как кластер поднимается.

В левой панели откройте "Space Explorer" и выберите любой узел, например `storage-A-1`.
В нём должен существовать спейс `test`.

Далее запускаем приложение. Необходимо открыть второй терминал и выполнить команды:
```shell
cd ./doc/examples/go_custom_encoder/go
go run -tags go_tarantool_ssl_disable main.go
```

> **Примечание**
> 
> Здесь для простоты мы отключаем поддержку TLS - `-tags go_tarantool_ssl_disable`, так
как для поддержки данного функционала требуется установленный OpenSSL 3.x. 

После того, как приложение отработает, вывод будет таким:
```shell
Recorded via crud in batches of 10000 records in 120.924997ms - auto-encoder
Recorded via crud in batches of 10000 records in 96.016347ms - custom-encoder
Rows verified
```

Необходимо убедиться, что в спейсе появились данные. Остановка кластера
производится командой:

```shell
docker compose down
```
