# Конфигурация и запуск кластера в CI
Особенностью работы в CI зачастую является запуск докера в докере. Либо запуск
докера в какой-то другой виртуальной среде. Следствием этого может быть
невозможность пробросить локальную папку в образ. Данный пример описывает как можно
выйти из данной ситуации.

Данный пример копирует пример [запуск и конфигурация кластера через docker compose](../up_with_docker_compose/README.md)
с небольшими изменениями.

Для этого примера понадобятся:
* Docker-образ TarantoolDB ([установить](../../INSTALL.md))
* Docker compose

Для запуска кластера из директории ``up_in_ci`` выполните:
```shell
docker compose up -d --build 
```

## Контейнер `user-host`
Здесь вместо проброса папки `./bootstrap` происходит сборка отдельного контейнера,
в который копируется данная папка и пользовательские скрипты.

Всё остальное работает так же, как и в основном примере.

## Останов стенда
Останов стенда производится командой:
```shell
docker compose down
```
