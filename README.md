# Примеры Tarantool DB

В этой ветке репозитория собраны запускаемые Docker-примеры для Tarantool DB 3.x. Каждый пример — это
самостоятельный стенд с файлами конфигурации, исходным кодом и файлом `README.md`,
содержащим пошаговую инструкцию.

Чтобы запустить пример, перейдите в его директорию и выполните следующую команду:

```shell
make start
```

Для остановки стенда выполните команду ниже:

```shell
make stop
```

Подробности работы приведены в `README.md` соответствующего примера. Для работы примеров требуются
установленный [Docker-образ](https://www.tarantool.io/docs/tdb/ru/3_x/install_and_upgrade/install/install_docker)
Tarantool DB и приложение Docker Compose; некоторые примеры дополнительно требуют
установленных Docker-образов Grafana и Prometheus,
утилиту [tt CLI](https://www.tarantool.io/docs/tdb/ru/3_x/install_and_upgrade/install_tt),
Go или Java.
