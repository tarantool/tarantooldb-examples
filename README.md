# Примеры Tarantool DB

В этой ветке репозитория собраны запускаемые Docker-примеры для Tarantool DB 1.x. Каждый пример — это
самостоятельный стенд с файлами конфигурации, исходным кодом и файлом `README.md` с пошаговой инструкцией по работе.

Большинство примеров запускается через Docker Compose:

```shell
docker compose up -d --build
```

Для остановки стенда необходимо выполнить команду ниже:

```shell
docker compose down
```

Точные команды для каждого примера приведены в `README.md` соответствующего примера. Для работы примеров
требуется установленный [Docker-образ](https://www.tarantool.io/docs/tdb/ru/1_x/install_and_upgrade/install/install_docker)
Tarantool DB и приложение Docker Compose. Некоторые примеры дополнительно требуют установленных Docker-образов Grafana и Prometheus,
утилиту [tt CLI](https://www.tarantool.io/docs/tdb/ru/1_x/install_and_upgrade/install_tt),
Go или Java.
